# Renderer

背景设置支持图片网址或本地文件路径，包括带引号的 Windows 路径。`useBackgroundImage` 在输入停顿后检查图片解码，忽略过期结果并安全引用 CSS URL。加载失败显示在背景设置旁，本地图片由主进程的专用协议提供。

Renderer 拥有 Island 显示与交互。Island.tsx 组合功能视图和 QuickView，useIslandController 组合功能 hooks；AppStateProvider 通过主进程服务载入并更新持久化状态，SettingsProvider 提供设置上下文。Ripple Next 使用新状态格式，不读取原 Ripple 的本地存储。

国际化在渲染前初始化。共享层随应用打包的词条定义翻译键；SettingsProvider 拥有 `language` 偏好，并将解析后的语言同步到托盘。日期和数值使用所选语言格式。中文与日语的概览日期在数字、月／日标记及星期之间留出空格。

`styles/base.css` 拥有透明文档、字体和共享动画，`styles/tokens.css` 拥有主题及字体变量；Island、共享控件和各功能视图分别拥有 CSS Modules。静态样式放入所属模块，Motion 参数和运行时颜色／几何值由原有职责模块管理。OverlayProvider 将 Select 菜单挂载在 Island 边界内，useIslandInteraction 统一管理移动、焦点、hover 和菜单打开时的交互。

搜索地址模板及时区偏好属于 AppState。时钟和日期使用 `Intl` 格式化；搜索校验和打开失败显示在 BrowserSearchTab 内。`InlineNotices` 将主进程错误路由到所属功能区，不再用 Island 浮层遮挡内容，并沿用原有淡入、模糊 Motion 过渡。设置滑块样式集中在 `SettingsTab.module.css`；竖排字段保留内容高度，横排字段分配可用宽度。

参见 [开发指南](../../docs/development.zh-CN.md) 和 [仓库地图](../../INDEX.zh-CN.md)。

下拉控件采用非模态单选菜单：打开时设置页面仍可滚动，在 Island 内关闭菜单不会切换展开状态。剪贴板历史仅记录可见文本，跳过纯图片与空内容。

快捷应用和工作流的启动错误在对应操作项内显示，重试时清除；媒体操作由媒体区域承担反馈。`InlineNotices` 只提供行内文字，不再绘制独立错误卡片。设置错误紧邻对应设置，剪贴板通过原生桥接读写，复制按钮承担复制成功或失败状态。

`ElasticScrollArea` 保留稳定的内容节点，纵向使用原生滚动及系统触控板惯性；仅在内容变化时测量尺寸，不运行永久动画循环。横向由 `TabPanels` 管理：方向触发切换，一段连续滚轮输入最多切相邻一页，首尾循环；过渡可以打断，模糊程度与窗口大小共用切换进度。多余距离只形成受限的弹性位移，不选择或露出第三页。原生触控板边界立即区分新手势；未提供原生边界时，以 150 毫秒输入空隙作为后备。嵌套横向控件优先滚动自身，到达边界后才交给页签切换。方向键重复输入逐次使用最新状态，各页键稳定，非活动页控件不可交互。

只显示分钟的时钟改为在分钟边界更新，恢复焦点或可见性时立即刷新。收起 Island 仍保留设备提醒和剪贴板历史采集。

概览电池徽章使用圆角电池主体和右侧灰色凸头，按电量百分比填充：充电时绿底白字，未充电时白底黑字；未填充部分始终为灰色，不随 Island 主题改变。数字不带百分号，与右侧实心充电图标在同一行整体居中。天气与电池共用顶部一行的字号和垂直对齐；充电电量为 100 时适当加宽徽章，不再缩小数字。

电池与设备提醒保留用户正在使用的展开页面；提醒结束时只退出快捷模式，避免启动时的充电提示定时器收起用户刚打开的页面。

横向弹性位移由持续的弹簧运动控制，滚轮输入和松手只更新目标。回弹途中再次输入时保留当前位置与速度，不再停止动画后直接重置位移。

导航使用连续的环形页面位置。新的切换请求从原进度经过正在进入的页面继续前进或返回，不替换半途中页面的内容，也不重置进度。`onScrollGestureStart` 原生边界让新触控板动作立即接管旧惯性流；150 毫秒空隙仅作为未提供原生边界时的后备。惯性输入减弱时，累计的弹性推力随时间衰减，不再等待所有事件停止才回弹。

上下滚动优先：只要含有 Y 分量，就将斜向手势交给原生纵向滚动，并撤销该手势已触发的横向请求。纵向轴保持到新手势边界或输入空隙，期间残留的横向事件不切页；只有纯横向输入才能启动标签导航。
