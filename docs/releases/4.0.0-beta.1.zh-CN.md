# Ripple Next 4.0.0-beta.1

这是 Ripple Next 的首个 beta 版本，采用全新的应用标识，并重新设计了设置、应用状态和集成服务的基础架构。

## 主要变化

- 应用状态保存在独立的 SQLite 数据库中，API key 使用操作系统安全存储。不会导入或迁移旧版 Ripple 数据，旧配置仍单独保留。
- 界面支持英语、简体中文、繁体中文和日语，可跟随系统语言；时区和浏览器搜索网址模板均可自定义。
- AI 助手支持 OpenAI 兼容接口，可配置 Base URL、模型和 API key。
- Linux 用户可以搜索已安装的桌面应用，也可以定义自定义启动目标；快捷应用栏支持横向滚动。
- 调整了设置页和 Island 交互，包括就地错误提示、可调鼠标离开延迟、后台模式、可搜索控件和滚动体验。

此 beta 版本用于试用与反馈。报告问题时请注明平台以及复现步骤。
