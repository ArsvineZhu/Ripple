# Ripple Next 4.0.0-beta.2

本 beta 主要改进 Island、AI 助手和平台集成路径的诊断能力与可靠性。

## 主要变化

- 新增本机诊断系统，提供结构化日志、崩溃转储，以及“关于系统”中的诊断目录入口。诊断记录不包含提示词、回答、API key 或剪贴板内容；崩溃转储仅保存在本机。
- 向内置 AI 系统提示词注入应用信息、所选时区和当前本地时间。
- 改进 AI 请求生命周期记录，并修整长内容和设置界面的滚动行为。
- 改进窗口与显示器同步，并记录 Linux 输入区域生命周期，便于排查问题。

此版本仍处于 beta 阶段。反馈问题时请注明操作系统和复现步骤。
