# Ripple Next 4.0.0

**Ripple Next's first stable release brings the floating Island, everyday tools and native integrations together on Windows, macOS and Linux.** Version 4.0.0 combines the new foundations introduced in beta.1, the diagnostics introduced in beta.2, subsequent cross-platform and gesture work, and the final music/workflow/PipeWire fixes.

## A new foundation for your desktop companion

Ripple Next has its own product identity, installers and profile. Preferences, tasks, workflows and quick apps live in a SQLite database with numbered migrations. API keys are encrypted with OS-backed secure storage and stored as ciphertext. The interface reads a typed state snapshot from main and updates it through validated IPC.

English, Simplified Chinese, Traditional Chinese and Japanese cover the interface and tray, with automatic system-language selection and immediate manual switching. Choose your time zone and search URL template, arrange or hide feature pages, and set the default page. Settings offers searchable selectors, snap/free positioning, background mode and an adjustable 0–2000 ms pointer-leave delay.

## Music cards for every player

The media service unifies session metadata, artwork, capabilities, automatic/manual choice and controls across Windows GSMTC, Linux MPRIS and running Spotify/Music on macOS.

- Vertical cards replace the player dropdown. **A** selects Automatic; dots inside the Island's right edge select individual players.
- Click, vertically scroll or focus the music area and use Up/Down/Home/End. One continuous gesture changes one card and stops at the ends; horizontal gestures switch feature pages.
- Manual choice stays with that player for the run. Stable session IDs, serialized requests and latest-choice queuing keep indicators, cards and controls aligned, including when a player closes.
- Expanded and QuickView covers share loading/failure behavior. Extensionless PNG/JPEG/GIF/WebP temporary artwork now displays on Linux, with the existing 5 MiB local limit.
- Clicking the cover opens the corresponding player through its native integration. The carousel follows reduced-motion preferences.

## A smoother Island

Feature pages animate along a continuous circular position, preserving the entering page during rapid navigation. Native vertical scrolling keeps long pages responsive. Horizontal swipes tolerate cross-axis drift, advance one neighbor per gesture, distinguish momentum from a fresh push and use a bounded elastic edge with a platform-derived release curve.

Pointer re-entry, input focus, menus and dragging keep interaction stable during movement and collapse. Device/charging notifications preserve an expanded page. The Overview battery badge fills to the remaining charge and changes to green while charging; localized dates retain readable spacing. The minute clock schedules updates at minute boundaries.

## Open your working context

Quick Apps supports installed applications, HTTP(S) URLs and custom executables with separate arguments and an optional working directory. Workflows launch targets in order, report errors on their own row and continue to later targets.

Local addresses such as `localhost:3000/` and IPv4 URLs with paths, queries and fragments now open in the default browser. Linux desktop entries use `gio launch`; Windows keeps original shortcut launch details and supports Store activation; macOS discovers application bundles in the standard Applications locations.

Clipboard text is read and copied through native Electron methods, with in-memory history for the current run. Tasks, workflows and quick apps persist between launches.

## Your AI endpoint, in the Island

Configure an OpenAI-compatible Base URL, model and API key. Responses stream with Markdown and code-block copy controls; cancellation and “Ask another” manage the current exchange. The bundled system prompt receives the product/version, repository information, selected time zone and current local time. Long answers grow to the available screen height and then scroll.

Keys stay in the main-owned secure store. On Linux, saving requires an encrypted OS backend. Request errors and lifecycle feedback stay with the assistant.

## Native integration and diagnostics

Windows improves Shell activation, app discovery/cache writes, GSMTC async/artwork handling, connected Bluetooth detection, and cursor-based input passthrough. Work-area sizing preserves auto-hide taskbar edges, and startup avoids taking focus.

macOS queries running media apps independently, shares capture-device reads and checks native login-item registration. Linux retains statically bundled X11, confirms ShapeInput before showing the Island, follows the active XDG autostart directory, and falls back from missing `pactl` to PipeWire `pw-dump` for microphone capture detection.

Settings opens local diagnostics. Main and renderer share a session ID; structured records cover lifecycle, displays/GPU, IPC outcomes, media/input backends and AI request timing. Logs omit credentials, user content and endpoint URLs. Dumps stay local, with startup retention of the newest 10 within 30 days. See [platform support](../platform-compatibility.md) for permissions and adapter details.

Four product READMEs present the eight tools with 12 screenshots captured from the real Linux application using a demo profile. Usage, architecture, platform troubleshooting and release acceptance have been refreshed.

CI runs checks/tests on all three OSes and packages all four architecture targets. The toolchain uses Node **22.23.3** and pnpm **12.9.1**. The [release guide](../release.md) covers publication and native runtime acceptance.

## Update your setup

Install a `RippleNext-…` package from the [release list](https://github.com/ArsvineZhu/Ripple-Next/releases). Beta users keep the Ripple Next profile and stored state. Users coming from older Ripple begin with the separate Next profile. When moving between OSes, re-select installed applications and enter keys protected by the destination OS. Start with the [usage guide](../../instructions.md).
