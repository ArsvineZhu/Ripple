# Ripple Next 4.0.0-beta.1

This is the first beta of Ripple Next, with a new application identity and a redesigned foundation for settings, app state, and integrations.

## Highlights

- State is stored in a dedicated SQLite database, with API keys kept in the operating system's secure storage. Existing Ripple data is not imported or migrated; the old profile remains separate.
- The interface supports English, Simplified Chinese, Traditional Chinese, and Japanese, with system-language selection, a configurable time zone, and a customizable browser-search URL.
- The AI assistant supports OpenAI-compatible endpoints with a configurable base URL, model, and API key.
- Linux users can discover installed desktop apps or define custom launch targets. Quick Apps supports horizontal scrolling.
- Settings and Island interactions have been refined, including inline error guidance, adjustable pointer-leave delay, background mode, searchable controls, and improved scrolling.

This beta is intended for evaluation. Please report regressions with the affected platform and the steps needed to reproduce them.
