# Ripple Next 4.0.0-beta.2

This beta focuses on diagnostics and reliability improvements across the Island, AI assistant, and platform integration paths.

## Highlights

- Adds local diagnostics with structured logs, crash reports, and an About System entry for opening the diagnostics folder. Diagnostic records omit prompts, answers, API keys, and clipboard contents; crash reports stay on this device.
- Adds application metadata, the selected time zone, and the current local time to the bundled AI system prompt.
- Improves AI request lifecycle reporting and scrolling behavior in long or settings views.
- Refines window/display synchronization and records Linux input-region lifecycle details for troubleshooting.

This is a beta release. Please include the operating system and reproduction steps when reporting an issue.
