# Ripple Next 4.0.0

**Ripple Next 首个正式版，将浮动 Island、日常工具和原生集成带到 Windows、macOS 与 Linux。** 4.0.0 汇集 beta.1 的新基础、beta.2 的本地诊断、随后跨平台与手势改进，以及正式版收尾的音乐、工作流和 PipeWire 修复。

## 桌面助手的新基础

Ripple Next 拥有自己的产品名、安装包和配置目录。设置、待办、工作流、快捷应用存入 SQLite，使用编号迁移维护结构；API 密钥由系统安全存储加密，以密文保存。界面从主进程读取类型化状态快照，通过经过验证的 IPC 更新。

简体中文、繁體中文、English、日本語覆盖界面与托盘，支持跟随系统和即时手动切换。可选择时区、搜索 URL 模板、页面顺序／隐藏／默认页。设置提供可搜索选项、吸附／自由定位、后台模式和 0–2000 ms 鼠标离开延迟。

## 每个播放器都有自己的卡片

媒体服务统一处理 Windows GSMTC、Linux MPRIS，以及 macOS 上运行中的 Spotify／Music，涵盖元数据、封面、控制能力与自动／手动选择。

- 播放器下拉框改为纵向卡片。**A** 选择自动模式，Island 内部右侧圆点对应各播放器。
- 点击、上下滚动或聚焦后按 Up／Down／Home／End 切换。一段连续手势换一页，到首尾停止；横向手势切换功能页。
- 手动选择在本次运行中保持。稳定会话 ID、串行请求与保留最新选择，让圆点、卡片和控制目标一致，播放器退出时也能恢复有效选择。
- 展开页与 QuickView 共用封面加载／失败恢复。Linux 现在可显示没有图片扩展名的 PNG／JPEG／GIF／WebP 临时封面，保留 5 MiB 本地上限。
- 点击封面经原生集成唤起对应播放器；卡片动画遵循减少动态效果偏好。

## 更流畅的 Island

功能页沿连续循环位置切换，快速操作保留正在进入的页面。长页面使用原生纵向滚动；横向手势容忍轻微偏轴，一次手势前进一个相邻页，区分惯性与新一轮输入，并使用有界弹性与平台曲线回弹。

指针重入、输入焦点、菜单和拖动保持移动／折叠期间的交互稳定。充电与设备提醒保留已展开页面。概览电池徽标按剩余电量填充，充电时变绿；本地化日期保留清晰间距，分钟时钟按分钟边界更新。

## 一次打开工作环境

快捷应用支持已安装应用、HTTP(S) URL，以及独立参数和可选工作目录的可执行命令。工作流按顺序启动，在对应行显示错误，并继续后续目标。

`localhost:3000/`、带路径／查询／片段的 IPv4 本地地址现在交给默认浏览器。Linux 桌面条目使用 `gio launch`；Windows 保留原快捷方式参数和工作目录，并支持 Store 激活；macOS 从标准 Applications 位置发现应用程序包。

剪贴板通过 Electron 原生方法读取／复制文字，历史保留在本次运行内存中；任务、工作流和快捷应用保存到下次启动。

## 在岛里接入自己的 AI

配置 OpenAI 兼容 Base URL、模型和 API 密钥，阅读流式 Markdown 回答并复制代码块；取消和“再问一个”管理当前问答。内置系统提示注入产品／版本、仓库信息、所选时区和当前时间。长回答增长到屏幕可用高度后滚动。

密钥由主进程安全存储管理，Linux 保存时使用系统加密后端。请求错误和生命周期反馈显示在助手页。

## 原生适配与本地诊断

Windows 改进 Shell 激活、应用发现与缓存写入、GSMTC 异步／封面读取、已连接蓝牙检测及光标输入穿透。工作区尺寸保留自动隐藏任务栏边缘，启动显示保持当前焦点。

macOS 分别查询运行中的播放器，共用采集设备读取，并检查原生登录项注册。Linux 保持 X11 静态打包、显示前确认 ShapeInput、遵循当前 XDG 自启动目录；缺少 `pactl` 时使用 PipeWire `pw-dump` 检测麦克风采集。

设置可以打开本地诊断。主进程与 renderer 共用 session ID，结构化记录覆盖生命周期、显示器／GPU、IPC 结果、媒体／输入后端和 AI 请求耗时。日志排除凭据、用户内容与端点 URL；转储保留在本地，启动时保留 30 天内最新 10 个。[平台支持](../platform-compatibility.zh-CN.md)说明权限与各适配器行为。

## 更新与开始使用

从[发布列表](https://github.com/ArsvineZhu/Ripple-Next/releases)选择 `RippleNext-…` 软件包。Next 测试版用户继续使用原配置和已保存状态；旧版 Ripple 用户使用独立的 Next 配置。跨系统迁移时重新选择已安装应用，并填写由新系统保护的密钥。完整操作见[使用指南](../../instructions.zh-CN.md)。
