# Using Ripple

Hover over the Island for Quick mode; click its non-interactive area to expand Large mode. Still is the compact idle state. Stealth hides it while inactive; Standby keeps Quick mode visible; Large Standby keeps the expanded view.

Navigate using arrow keys, horizontal wheel/trackpad gestures, or Ctrl+1 through Ctrl+8 in configured visible-tab order. The Now Playing tab appears when a media source is available. Settings can reorder/hide tabs and select the default tab.

The eight tabs are Browser Search, Workflows & Quick Apps, Overview, Now Playing, AI Assistant, Clipboard, Tasks and Settings. Workflows launch their configured apps/URLs in order. Configure Groq/OpenRouter provider, model and your API key in Settings. Clipboard history belongs to the current session; tasks, workflows, quick apps and preferences are persisted.

Settings control time format, boot startup on Windows/Linux, display, snap/free positioning, theme/colors/background, border, inactive/standby behavior, battery alerts, weather location/unit, quick apps and workflows. Linux media/status features require the optional commands listed in the [developer guide](docs/development.md).

Settings → General → Language offers Follow system, 简体中文, English, 繁體中文 and 日本語. Selection applies immediately to the interface and tray and is remembered after restart. Switching language retains your draft inputs and saved data.

Use arrow keys and Enter inside a dropdown; Escape closes it and returns focus to its trigger. Tab navigation shortcuts apply outside interactive controls. Position Mode keeps the settings view open at its new location. Workflow input width is fixed to its form.
